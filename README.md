# 無料ネット安全診断 / GitHub Pages公開セット

## 公開
1. GitHubで **Public** の新しいリポジトリ `net-safety-check` を作成する。
2. このZIPの中身（`index.html`, `article-images/`, `articles/`）をリポジトリのルートにアップロードしてコミットする。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save。
4. 数分後、`https://cz9059-cell.github.io/net-safety-check/` を開き、スマホでも操作確認。

## 公開前の確認
- 5問すべてに回答するとおすすめのチェックに移動できるか
- 6つの説明パネルが開閉できるか
- 公式サイトへの外部リンクが開けるか
- 各サービスの権限・画面名は変わるため、公開前と定期的に最新情報を確認する
- 本診断は安全性の判定・保証ではない。回答内容やパスワードは収集しない
- article-imagesは既存の絵を切り出して指定サイズに整えた暫定素材。独立した再描画ではない

※ GitHub Pages の公開設定は、このZIPを作った時点では未実施です。
